Snake-Protocol:

+-------------+----------+---------+
| length: u32 | type: u8 | payload |
+-------------+----------+---------+
// length of type + payload

Server Outgoing:
types:
0x00 => EntireState
+--------------------+----------------+-----------------+
| apples: xyxyxyxyxy | board_size: xy | snakes: (below) |
+--------------------+----------------+-----------------+
snake:
+-------------------+--------------------------------+
| length_bytes: u16 | segments: dir,xy,dir,xy,dir,xy | // dir: 0x00-0x03, x,y: u16
+-------------------+--------------------------------+

0x01 => AddApple
+-----------------------+
| positions: xyxyxyxyxy | // where x,y: u16
+-----------------------+

0x02 => RemoveApple
+-----------------------+
| positions: xyxyxyxyxy | // where x,y: u16
+-----------------------+

0x03 => AddSnake
+----------------+----------------+--------------------------+
| player_id: u64 | dir: 0x00-0x03 | segments_pos: xyxyxyxyxy | // where x,y: u16
+----------------+----------------+--------------------------+

0x04 => RemoveSnake
+----------------+
| player_id: u64 |
+----------------+

0x05 => SnakeMovement
+----------------+----------------+
| player_id: u64 | dir: 0x00-0x03 |
+----------------+----------------+

0x06 => TickFinished
// no payload for now
