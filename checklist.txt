## Cool Idea ##
###############

- Multiple server behind one proxy
  - multiple game modes with gimmicks -> inspo google snake
  - proxy has list of available game modes
      - Client can choose and proxy routes traffic to that server.
  - proxy has local discovery port where servers can register
      - transmit their port(+ip) and game mode.

  -Client receives packet with list of all game modes
    -> chooses one sends that to proxy
    -> from there proxy behaves like the normal server
  - direct connection with server also simple
    -> server sends available game modes anyway

  - Normal
  - Invincible
  - Walls -> needs client changes for rendering
